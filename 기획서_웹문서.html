01 무엇을 만드나

프로그램은 "검수 가능한 완성 콘텐츠"까지 만든다. 검수와 발행은 사용자 몫.

✍️ AI 초안

주제·키워드를 넣으면 사용자 문체를 반영한 제목·본문 초안을 생성.

🖼️ 이미지 확보

주제에 맞는 저작권 안전 이미지를 자동 수집하거나 AI로 생성.

🔍 검수 화면

발행 정보·체크리스트·본문을 한 화면에. 확인 후 복사해 발행.

02 왜 자동 발행은 안 하나

네이버는 글쓰기 공식 API가 없다. 매크로 강제 업로드는 저품질·계정 제재 위험.

확정 방침 — 프로그램은 네이버 계정에 접근하지 않는다. 콘텐츠 생성은 자동, 검수·발행은 사용자가 직접. 개인 브랜딩이 목적이라 제재 = 브랜드 손상이므로, 안전이 최우선이다.

💡이 방식이 정책 안전 + 품질 확보 + 구현 단순화를 모두 잡는다. 네이버 로그인/업로드 코드가 통째로 빠진다.

04 이미지 확보 전략 실검증 완료

"국가 축의금" 주제로 실제 3단계를 돌려본 결과.

순위소스테스트 결과판정
1정부 사이트 직접 다운로드재정경제부·정책브리핑 403 차단스크래핑 불가
1공식 오픈API (정책브리핑·공공데이터포털)무료 인증키 발급 시 이미지 URL 정상키 필요
2Pixabay 무료 스톡사용자가 API 키 보유즉시 연동
3AI 생성 (nano-banana)대표 이미지 실제 생성 성공작동 확인
⚠️정부 사이트 무단 스크래핑은 막혀 있고 저작권 위험도 있음 → 공식 API 경유. AI 이미지의 한글 텍스트는 부정확하니 글자 없는 일러스트로. 최종 저작권 확인은 사용자 검수 항목.

05 단계별 로드맵

완벽한 문서보다, 한 바퀴 돌려보고 고치기.

  1. 1단계 · 수동으로 흐름 검증 (1~2주)주제 5개·톤 정하고, AI 초안 → 손으로 발행까지 직접 해보며 가장 번거로운 단계 파악.
  2. 2단계 · 콘텐츠 생성 자동화 MVP (2~4주)초안 + 이미지(Pixabay/AI) 자동화, 웹 미리보기(B) + 검수 체크리스트.
  3. 3단계 · 최적화·확산 (1~2개월)SEO 키워드·해시태그 보조, SNS 확산 문구, 성과 기반 주제 뱅크 개선.
