# 숏폼 생성기 (Shortform Generator)

유튜브 쇼츠형 9:16 세로형 숏폼 썸네일을 만들고 PNG로 내보내는 브라우저 도구입니다.

## 스타일 구성

참고 스타일을 기반으로 다음 레이어를 자동 합성합니다.

- **상단 흰색 헤더**: 채널 로고 + 채널 ID/채널명, 그 아래 **검정 굵은 제목**(2줄, 자동 줄바꿈)
- **배경 이미지**: 헤더 아래 영역을 9:16 `cover` 방식으로 크롭 정렬
- **상단 라벨**: 빨강 강조 박스 + 나머지 텍스트 (예: `매운맛 VS 행복맛`)
- **중앙 자막**: 흰색 + 검정 외곽선 굵은 자막
- **댓글 카드**: 유저·시간·댓글 내용·좋아요 수·답글
- **하단 출처 캡션**: 흰색 + 검정 외곽선

## 영상 출력 (타임라인)

정지 이미지뿐 아니라 자막·댓글이 **시간대별로 바뀌는 영상(webm)** 도 만들 수 있습니다.

- **자막 큐**: `시작초,끝초,문구`를 한 줄에 하나씩 입력 → 시간대별로 자막 자동 교체
- **라벨/댓글 카드**: 각각 등장·퇴장 시간 지정 + 페이드 인/아웃
- **배경 영상** 업로드 지원 (이미지 대신 영상 위에 오버레이)
- **재생 미리보기 / 영상 녹화(webm) / PNG 내보내기** 3가지 출력

> 녹화는 브라우저의 `canvas.captureStream` + `MediaRecorder`로 동작하며, 영상 길이만큼 실시간으로 진행됩니다. webm은 대부분의 편집 앱에서 불러오거나 mp4로 변환할 수 있습니다.

## 사용법

1. `index.html`을 브라우저에서 엽니다. (별도 서버 불필요)
2. 배경(이미지/영상)을 올리고 텍스트·타임라인을 입력하면 미리보기가 갱신됩니다.
3. **PNG 내보내기**로 이미지 1장, **영상 녹화(webm)**로 움직이는 숏폼을 저장합니다.

## 파일 구조

```
index.html   구조 / 편집 폼
style.css    다크 UI 스타일
app.js       1080×1920 캔버스 렌더링 · PNG 내보내기
```

## 향후 확장 아이디어

- 프리셋 저장/불러오기 (로컬 스토리지)
- 텍스트 위치·색상·폰트 크기 커스터마이징
- 폰트 임베드 (웹폰트) 및 그림자/외곽선 옵션
- 여러 장면을 이어 붙인 영상(mp4) 출력
