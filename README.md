# 🎬 롱폼 모션 영상 생성기 (`longform.html`)

타임스탬프 대본 + 장면 이미지 → **모션그래픽이 들어간 16:9 롱폼 영상(MP4)** 을 무료로 만드는 브라우저 도구입니다. 서버·유료 API 없이 내 브라우저에서 처리합니다.

1. `longform.html`을 크롬/엣지(또는 안드로이드 크롬)로 엽니다.
2. **① 타임스탬프 대본**을 붙여넣습니다: `(0:00) 문장` / `[1:23] 문장` / `1:02:03 문장` 한 줄에 한 장면.
3. **② 이미지**를 한꺼번에 선택합니다. 파일명 `0-00`, `0-06`, `1-23`(또는 `1-02-03`)을 보고 해당 장면에 자동 배치됩니다. 나레이션 음성(선택)도 넣습니다.
4. **③ 모션그래픽**: 장면 전환(크로스페이드·밀어내기·줌·화이트 플래시·자동 섞기·컷), 움직임 강도, 효과 자동, 자막(선택)을 고릅니다.
   - 장면 카드마다 움직임(줌 인/아웃, 좌우·상하 패닝, 쿵! 강조 줌, 고정)과 효과(₩ 코인, ✧ 반짝, ❗, ❓, 📈/📉 화살표)를 따로 지정할 수 있어요.
   - 효과 '자동'은 대본 단어(가격·돈·월급 → 코인, 왜·? → 물음표, 충격·! → 느낌표, 상승·증가 → 상승 화살표 등)를 보고 고릅니다.
   - 자막에서 `*단어*`처럼 별표로 감싼 단어는 빨간색으로 강조됩니다.
5. **▶** 로 미리보고, **🎬 영상 만들기**로 MP4를 저장합니다.
   - 빠른 모드(WebCodecs): 영상 길이보다 빠르게 만들어요. 3분 넘는 영상은 PC 크롬/엣지에서 저장 위치를 먼저 물어보고 디스크에 바로 씁니다(메모리 절약).
   - 지원하지 않는 브라우저는 자동으로 실시간 녹화로 바뀝니다(영상 길이만큼 화면을 켜두세요).

> 대본·설정은 자동 저장되지만, 이미지·음성은 다시 열 때 다시 선택해야 합니다(파일명 매칭이라 한 번에 끝나요).

# 썰 슬라이드 숏폼 생성기

"썰 채널" 스타일의 **이미지 나열식** 9:16 숏폼을 만드는 브라우저 도구입니다.
상단 노란 제목 바 + 본문/일러스트 슬라이드 + 하단 채널 바 구성을 그대로 재현하고,
슬라이드를 순서대로 재생하거나 영상(webm)으로 녹화합니다.

## 스타일 구성

- **상단 검정 제목 바**: 1줄(흰색) / 2줄(노란 하이라이트)
- **중앙 흰 영역**: 본문 텍스트(줄바꿈 가능) + 일러스트/이미지(가운데 맞춤) + 노란 강조 캡션
- **하단 검정 채널 바**: 채널 로고 + 채널명 + 가입 버튼 + 하단 제목 + ▶ 재생 캡션

## 사용법

1. `index.html`을 브라우저에서 엽니다. (별도 서버 불필요)
2. 상단 제목·채널 바 텍스트를 입력합니다.
3. **＋ 슬라이드 추가**로 슬라이드를 만들고, 각 슬라이드에 이미지·본문·강조 캡션·길이(초)를 넣습니다.
4. **◀ ▶** 로 슬라이드를 미리 보고, **▶ 재생 미리보기**로 흐름을 확인합니다.
5. **● 영상 녹화(webm)** 로 전체 슬라이드를 이어붙인 영상을 저장합니다. (현재 슬라이드 1장은 **PNG**로도 저장 가능)

## 출력

- **PNG**: 현재 슬라이드 1장 (1080×1920)
- **webm**: 모든 슬라이드를 각 길이만큼 이어붙인 영상 (브라우저 `canvas.captureStream` + `MediaRecorder`)

> webm은 대부분의 편집 앱에서 불러오거나 mp4로 변환할 수 있습니다. 녹화는 전체 길이만큼 실시간으로 진행됩니다.

## 📱 휴대폰 연동 (`pixabay-local.html`)

- **자동 저장**: 제목·대본·자막·칸별 프롬프트/검색어·AI/URL 이미지가 브라우저에 자동 저장돼, 새로고침해도 그대로 남습니다.
- **휴대폰으로 보내기 (QR·링크)**: PC에서 누르면 QR이 뜹니다. 휴대폰 카메라로 스캔하면 같은 작업이 휴대폰에서 열립니다.
  QR이 너무 길면 **복사/공유**로 링크를 카톡 '나와의 채팅' 등에 보내 여세요.
  - PC에서 파일로 열었을 때는 '휴대폰에서 열 주소'(기본: `https://five-green-11.vercel.app/pixabay-local.html`)로 연결됩니다. 다른 주소에 올렸다면 그 주소로 바꾸세요.
  - 링크에는 **음성 파일과 직접 올린 사진은 빠집니다** (픽사베이 API 키도 전달되지 않음).
- **프로젝트 파일 저장 / 열기**: 음성·모든 이미지까지 담은 `ssul-project.json`을 만듭니다. 카톡/드라이브로 휴대폰에 보내고 **프로젝트 파일 열기**로 불러오면 완전히 똑같이 이어서 작업할 수 있어요. (반대로 휴대폰 → PC도 동일)
- **휴대폰에서 영상 저장**: 아이폰(사파리)은 mp4, 안드로이드(크롬)는 webm으로 저장됩니다. 녹화 중에는 화면을 켜둔 채 기다리세요. 자동으로 안 받아지면 상태 줄에 뜨는 링크를 누르세요.
